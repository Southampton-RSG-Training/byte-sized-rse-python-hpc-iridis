# Byte-Sized RSE
# HPC and Python with Iridis at Southampton

This a course covering how to use Python and SLURM to run simple 'embarrassingly parallel' computations on the University of Southampton's Iridis 6 supercomputer cluster.

It includes an introduction to HPC derived from the Southampton RSG's [Intro to HPC](https://github.com/Southampton-RSG-Training/intro-to-hpc) course; along with a new discussion of the challenges of concurrency in Python code and a worked example of using Pytorch to perform data augmentation on a data set.

It follows the Byte-sized RSE formula of a brief introductory lecture, followed by an example where students can work alongside the instructor to learn the material.
